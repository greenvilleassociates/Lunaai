# Color Replacement Guide

Replace all instances of:
- `#8B0000` → `#5b6b8f` (periwinkle blue)
- `#6B0000` → `#4a5a7f` (darker periwinkle for hovers)
- `#a00000` → `#4a5a7f` (darker periwinkle for hovers)
- `#a00` → `#4a5a7f` (darker periwinkle for hovers)
- `#660000` → `#4a5a7f` (darker periwinkle for hovers)

Also update category colors in AdminReports getCategoryColor function to use softer tones.
